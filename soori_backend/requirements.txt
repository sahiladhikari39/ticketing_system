# Every version below is PINNED to an exact number, not left open.
#
# This file used to have no versions at all -- just "django",
# "djangorestframework", etc. That meant every fresh install grabbed
# whatever was newest on PyPI *at that moment*. This bit hard once
# already: Django 6.1 removed something internal
# (django.utils.cache.cc_delim_re) that this exact version of DRF
# still expects, so a brand-new install broke with an ImportError that
# had nothing to do with anything in this project's own code.
#
# Pinning means "pip install -r requirements.txt" installs the SAME
# versions every time, on every machine, forever -- what's tested here
# is exactly what runs anywhere. Upgrading later is a deliberate,
# tested decision, not something that happens by accident because a
# venv got recreated.
